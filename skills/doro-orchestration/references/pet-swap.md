# 한 도로만 표시하는 교대 절차

공식 펫과 전용 펫을 동시에 띄우지 않는다. 공식 펫의 그림·대화 UI를 패치하거나 계정 토큰을 가져오지 않는다. 현재 Work에서 제공되는 공식 Pets의 목록·선택 기능만 사용한다. 처음 적용할 때 `work-pets:pets` 스킬을 읽고 현재 선택을 확인한다. 로컬 `pet-swap`은 표시 사용권 장부이며 실제 선택 API가 아니다.

## 협업 시작 또는 전용 대화 다시 열기

0. `active_pet_id: default`는 선택 응답일 뿐 실제 데스크톱 펫 숨김의 증거가 아니다. 기본 파란 펫이 남는 사례가 확인됐으므로 현재는 자동 교대를 완료로 취급하지 않고 마스코트 없는 `--display panel`을 사용한다. 지원되는 화면 확인이나 사람의 현재 확인으로 공식 펫이 실제로 사라졌음이 검증된 경우에만 아래 통합 절차를 진행한다.
1. `chat <세션> --display hidden`으로 빌드를 미리 확인한다. 실행 중 창이 있으면 숨김 확인 응답까지 기다린다. 기존 사용권이 있는 동안 다른 맥락의 창을 불필요하게 숨기지 않는다.
2. 공식 `list_pets`의 실제 `active_pet_id`를 읽는다. 이름이나 로컬 persona 플래그로 추측하지 않는다. 현재 ID가 `default`이고 기존 장부에도 원래 ID가 없으면 복귀 대상을 알 수 없으므로 통합 교대를 시작하지 않는다.
3. `pet-swap prepare <세션> --owner-thread <현재 Work> --observed-pet <실제 ID>`로 같은 소유 Work의 사용권을 등록한다. 이미 교대 중이면 실제 선택 `default`와 기존 원래 ID를 유지하며 같은 네이티브 창을 공유한다.
4. 첫 사용권이면 공식 `select_pet`에 `pet_id: "default"`를 전달한다. 응답의 실제 `active_pet_id`가 `default`인지 확인한다. 선택 성공과 실제 화면 숨김을 각각 확인하기 전에 전용 펫을 띄우지 않는다. 기본 펫이 보이거나 확인할 수 없으면 저장한 원래 선택을 복원하고 사용권을 해제한 뒤 panel 모드를 쓴다.
5. `pet-swap active <세션> --owner-thread <현재 Work> --observed-pet default`를 기록한 뒤 `chat <세션> --display integrated`를 실행한다. 기존 창은 같은 프로세스에서 스택을 전환한다. 실제 표시 확인 응답이 오지 않으면 표시 완료를 주장하지 않는다.

## 종료·취소·공식 도로 복귀

1. 끝난 협업의 사용권만 `pet-swap release <세션> --owner-thread <현재 Work>`로 해제한다. 준비 중 실패한 사용권도 같은 명령으로 해제할 수 있다. 다른 소유 Work의 사용권을 임의 해제하지 않는다.
2. 다른 사용권이 남으면 같은 전용 도로를 유지한다. 마지막 해제일 때 `restore_needed: true`, `stage: restoring`이 된다.
3. `chat <세션> --display stop`으로 전용 창이 숨겨졌다는 확인 응답을 받은 뒤 복귀한다. 실행기가 이미 종료된 경우 단일 인스턴스 잠금으로 프로세스 부재를 확인한다. 타임아웃·새 요청에 의한 대체·미확인 상태에서는 두 번째 펫을 복원하지 않는다.
4. 공식 목록을 다시 읽는다. 여전히 `default`일 때만 저장해 둔 정확한 `original_pet_id`를 공식 선택 도구로 복원한다. 사용자가 다른 펫을 골랐다면 그 선택을 존중하고 덮어쓰지 않는다.
5. 실제 선택을 확인하고 `pet-swap restored --observed-pet <실제 ID>`를 기록한다. 원래 ID는 `restored`, 사용자가 고른 다른 ID는 `superseded`로 남는다. 장부가 성공이라고 했다는 이유만으로 실제 선택 성공을 주장하지 않는다.

전환 중 오류가 나면 준비한 사용권 해제·전용 창 중지·실제 선택 확인을 거쳐 복구한다. API 실패를 숨기거나 다른 ID를 기본 복귀 대상으로 만들지 않는다. 중간에 Work가 종료되거나 도구 연결이 끊기면 즉시 복구를 보장할 수 없다. 다음 명시적 요청에서 장부와 실제 선택을 대조해 복구한다. 독립 네이티브 앱은 공식 MCP 선택 도구를 직접 부를 수 없으며 ‘공식 도로로 돌아가기’ 메뉴는 현재 Work로 보내는 로컬 요청이다. Work가 쉬는 중이면 수신 대기로 표시한다.

접기는 대화만 숨겨 도로를 남기는 동작이다. 협업·사용권 해제·공식 복귀와 구분한다. 공식 도로를 숨기는 단축키로 Option+Space를 안내하지 않는다. 이 단축키는 표시·포커스 기능이다.
